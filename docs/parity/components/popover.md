## popover

Upstream: [docs](https://sap.github.io/fundamental-ngx/#/core/popover) · [source](https://github.com/SAP/fundamental-ngx/tree/main/libs/core/popover)

### Gaps to fill

- **Stories:** "In a dialog" — trigger inside a dialog, Escape closes only the popover; "Append to" — `appendTo` an outlined element; "CDK positions" — custom `cdkPositions` with fallbacks; "Scroll strategies" — reposition / noop / close / block side by side; "Dropdown" — button + menu body, with icon, disabled; "Resizable" — `resizable` body with min/max sizes and a footer; "Focus handling" extended with header/footer close buttons and `preventSpaceKeyScroll=false`. Decide on Mobile mode, lazy body and container-resize refresh (port or document as dropped).
- **Tests:** "Escape inside a dialog closes only the popover"; "header and footer stay in place while the body scrolls"; "body minWidth, minHeight and maxHeight size the body"; "additionalBodyClass is added to the body"; "resizable shows a handle that resizes the body"; "disableScrollbar removes the scroll wrapper"; "bodyRole null renders no role; bodyAriaLabelledBy labels the body"; "a non-focusable control becomes tabbable and opens with Enter/Space"; "setIgnoreTriggers stops triggers until reset"; "config input sets defaults that inputs override"; "isOpen true on creation opens the popover"; "changing closeOnOutsideClick while open takes effect"; "destroying an open popover removes its overlay"; "applyOverlay dims the page when the popover cannot be dismissed"; "cdkPositions and applyNewPosition move the body; refreshPosition follows a moved trigger"; "changing the trigger moves the listeners"; "an outside click on a focusable element keeps focus there; on a non-focusable element focus returns to the trigger"; "setting isOpen false returns focus to the trigger"; "closing via focusout does not move focus back".
